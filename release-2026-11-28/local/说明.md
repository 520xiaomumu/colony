# Colony 本机守护服务（单进程双端口）

零配置即开即用的 Colony 本机配套目录（需 Node.js 18+）：

- **控制面 `:4130`**（强制锁死 `127.0.0.1`，绝不外放）：供 Colony「本机」面板与全能 agent 执行终端命令、读写文件、热更守护源码与自动快照回滚。
- **数据面 `:4135`**（同进程启动 `sub/gateway.mjs`，物理隔离无命令执行权限）：本地私有 OpenRouter 聚合网关，统一聚合 5 家订阅（ChatGPT / Claude / Antigravity / Grok Build / Cursor）、常规 API 厂商与浏览器网页反桥模型，兼容 OpenAI `/v1`、Anthropic `/v1/messages` 与免跨域 `/proxy`。

## 一键上手（推荐）

- **Windows**：双击 `启动 Colony.bat`
- **macOS / Linux**：双击 `启动 Colony.command`（或终端执行 `sh "启动 Colony.command"`）

首次运行会自动完成三件事：
1. 在后台静默启动 `:4130` 与 `:4135`；
2. 配置开机静默自启（Windows 写入当前用户启动目录并免管理员注册 `colony://` 网页一键唤醒协议；macOS 写入 `~/Library/LaunchAgents/fun.colony.local.plist`）；
3. 自动打开旁边的 `colony.html`（此后即使进程被关闭，也可直接在网页点击「一键唤醒」拉起服务）。

## 命令行用法

```bash
node colony-local.cjs              # 前台启动
node colony-local.cjs --install    # 安装后台自启 + 注册 colony:// 网页唤醒协议
node colony-local.cjs --uninstall  # 卸载自启与唤醒协议并停止正在运行的服务
```
