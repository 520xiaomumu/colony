## Colony 的哲学（精简版）

完整版见 [Colony哲学与迭代宪法.md](Colony哲学与迭代宪法.md)（2026-11-07 修订，文末有修订记录）。

**定义。** Colony 是一个单文件、可自我阅读和改写、能繁殖的"活"软件个体——Smalltalk image 与 Lisp machine 的 Web 时代、AI 原生后裔，本体装在一个 HTML 文件里。全能 agent 不是产品旁边的聊天框，是住在产品里、能改产品自己的住户：你不是装应用，是养应用。

**护城河。** 一个能被无限改写而不腐烂的透明单文件。形态（单文件、开源、人人可解释）是表，治理（抗熵增的迭代制度）是里。

**三根支柱。**
- **透明与自掌握**：源码 → 解读 → 追溯对任何人成立，小朋友也不例外；"没有做不了，只有还没读"；给用户看的执行过程必须是真实发生的。AI 是助产士，不是生命本身。
- **繁殖**：Stem 似细胞核，agent 似精子，Stem+Petri 似卵；蜕皮出下一代，血统如实记录。交换的不是账号，是一个 HTML。
- **进化与韧性**：筛选权在用户手里；断网可活、旧机可跑、平台消亡它还在。

**壳：插件 ≈ WebView，插件 + 本机 ≈ Electron。** 本体是网页；它按需长出薄壳去够真实世界：

| 层 | Colony 里是 | 像什么 | 给了什么 |
| --- | --- | --- | --- |
| 本体 | `colony.html`（Stem + 块 + 小应用） | 网页 | 一切逻辑、界面、记忆 |
| 浏览器层 | 插件管理块 + Colony Bridge 插件 | WebView | 碰到你的真浏览器：带 cookie 代发请求、标签页、CDP、脚本、录屏 |
| 本地层 | 本机块 + `colony-local.cjs` | Electron（网页外壳 + 本地 Node） | 碰到你的电脑：跑命令、读写文件；今天是 Windows 上的 app 外壳，后续有安卓、苹果的 app petri |

取魂不取形：要 WebView / Electron 的魂（网页碰到宿主、网页加本地能力），不要它们的形——不自带浏览器内核、不打包运行时，壳只是一个零依赖的脚本。厚壳仍是历史错误。

**迭代宪法要点。**
- Stem 冻结，功能一律下放成块；宿主层只缩不胀。
- 改 Stem 或基因表要修宪；改判写明新旧差异——宪法不怕认错，怕静默。
- 不变式进门禁，测试先于实现；孤儿可活：任何块、任何壳缺席都不让整体死。
- 先删后增，每刀留账，删回是机械操作。
- 流通安全前置：外来的定义、技能、插件零执行落库、默认禁用。
- 壳与外延（新增）：壳层层可拔；壳是哑管道、不住逻辑、可被 Colony 改并能退回；手越长边界越明，密钥不出本机；人机同路，后台做的事记账可撤回。
