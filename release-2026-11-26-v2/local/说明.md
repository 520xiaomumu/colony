# 本机 · 说明(11-04, 最基础版)

两样东西: **colony-local.cjs** 是在电脑上跑的小程序(Node 18 以上, 一个文件, 不用装别的);
**petri-local.html** 是 Colony 的「本机」块, 装上后全能 agent 能用这台电脑跑命令、读写改文件。

## 1. 启动小程序
1. 建一个单独的文件夹(例如 `C:\Users\你\colony-local\`), 把 colony-local.cjs 放进去。
   它能改自己所在文件夹里的文件, 别放进「下载」「桌面」这种杂的地方。
2. 在这个文件夹里开终端, 运行 `node colony-local.cjs`, 看到「colony-local 在 http://127.0.0.1:4130 …」就好了。
   关了终端它就停了。换端口加 `--port 4131`。
3. 开机自动在后台跑: `node colony-local.cjs --install`。
   - Windows: 在「启动」文件夹放一个 colony-local.vbs(隐藏窗口启动, 不要管理员), 并马上在后台起一个。
   - 手机 Termux: 写 `~/.termux/boot/colony-local.sh`; 要装 Termux:Boot 应用并打开它一次。
   - 别的系统: 只打印一行 crontab 的做法, 自己加。
4. 撤掉: `node colony-local.cjs --uninstall`(删掉启动项, 正在后台跑的那个也停掉)。

## 2. 装进 Colony
1. 打开你的 Colony, 点顶栏的 ⚙(Stem 面板)。
2. 点「⬆ 导入 Petri」, 选 petri-local.html, 提示「petri:local → 已收养(禁用, 启用后上岗)」。
3. 在 petri:local 那一行点「启用」, 顶栏多出「本机」亮框。
4. 点「本机」亮框开面板: 已连上就显示这台电脑的信息; 没连上就照面板上的命令启动小程序, 再点「重连」
   (端口不是 4130 就先改地址框)。地址会记住, 以后打开 Colony 自己连一次。

## 3. agent 多了什么
- 直接当工具的 6 个: `local.run` 跑命令、`local.job` 看后台命令的新输出、`local.read` 按行读文件、
  `local.write` 整份写、`local.edit` 改一处(old 换 new, old 不唯一会报出现几次)、`local.ls` 列目录。
- 另外 12 个在 agent 的目录里(用 call 调): `local.info` `jobs` `stop` `input` `restart` `connect`
  和 `src.list` `src.read` `src.write` `src.edit` `src.backups` `src.revert`。
- 命令: Windows 默认 PowerShell(输出设成 UTF-8), 别的系统 `sh -c`。30 秒(wait, 最多 590 秒)内没跑完,
  回一个 id, 进程留在后台; `local.job` 接着看, `local.stop` 停(连子进程一起杀), `local.input` 往里打字。
  输出每路留开头 1 万字 + 结尾 2 万字, 中间省掉的会写明省了多少字。
- 「本机」块的技能段教了 agent 这些用法(系统提示里有它的名字)。没连上时调 local.* 会回:
  「本机没连上：先在电脑上运行 node colony-local.cjs（见「本机」面板）」。
- 面板里还能看后台进程的输出、停掉它们。

## 4. 改小程序自己的源码、退回
- agent 用 `local.src.*` 改小程序目录里的任意文件, 写前自动快照, 每个文件留 5 版, 快照在 `.colony-local/` 里。
- 改完要 `local.restart`(或面板「重启本机脚本」, 点两下): 新版 10 秒内能起来就换成新版, 在后台跑,
  输出写进 `.colony-local/out.log`; 起不来就自动把文件恢复成这次启动时的样子, 旧的接着跑,
  报错的最后几行在 `local.info` 和面板里。
- 要回到更早的版本: 面板里文件旁点「▸ 快照」→「退回这一版」(点两下)→「重启本机脚本」。
- 重启会停掉正在跑的后台进程。

## 5. 已知限制
- **没有密码**(这次定了不做)。默认只听 127.0.0.1, 但这台电脑上任何程序、任何网页都能连它跑命令。别用 `--host 0.0.0.0`。
- Colony 用 https 网址打开时, Chrome 第一次连本机会问「允许访问本地网络」, 要点允许。这条没测, 测的是本地文件打开。
- agent 的停止按钮只停模型那头, 已经在跑的命令不会跟着停, 要用 `local.stop` 或面板的「停」。
- 没做边跑边看: 命令输出要等 run / job 回来才看得到。后台进程列表只在小程序内存里, 它重启或关掉就没了。
- Windows 上自己用 GBK 输出的老程序, 在 PowerShell 里可能还是乱码(python 已设 UTF-8 输出, cmd 用 chcp 65001)。
- 只在 Windows 11 + Node 24 + PowerShell 5.1 上测过; Termux、macOS、Linux 没测, 那边的 `--install` 也没测。

## 6. 以后要补的安全
先加口令: 小程序第一次启动生成一串随机口令, Colony 第一次连上时人确认一下, 之后每个请求都带, 不对就拒。
再按需加: 只许在哪些目录读写、危险命令先问人。

## 7. 文件和检查
- `petri-local/`: 块的段文件和清单; 改完用 `分支/colony-tools.mjs pack` 拼(要 `--stem` 指新版 Colony)。
- `test-local.mjs`: `PORT=4191 node test-local.mjs`(端口用 4190~4199)。在临时目录真起小程序测 16 项,
  再查块的写法 3 项(每行不超过 110 字、「跟着」写全、清单); 「跟着」那条借用 `分支/test-petri-workflow.mjs` 里的分析。
