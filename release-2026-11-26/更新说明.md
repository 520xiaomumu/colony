# Colony 11.26 更新说明

对比上一版 `release-2026-11-07`（v11.7）。本版是从零散增强走向「全能 agent 重构 + 网页模型/网站插件引擎 + 本机订阅中心」的一次大升级。

## 1. 全能 agent（`petri:agent`）：第一档 5 项架构重构完成
- **主对话与后台 worker 共用引擎**：统一工具调用、并发调度、循环防卡死与错误处理逻辑，代码更精简、行为更一致。
- **动态上下文截断与阶梯折叠**：按模型上下文窗口动态控制工具回传长度，旧轮工具结果自动阶梯折叠，长任务不轻易爆上下文。
- **精简系统提示与按需自报**：大幅压缩开场常驻 token，技能说明与扩展插件目录全部改为按需读取。
- **对话栏懒加载与渲染优化**：长历史对话渲染更轻快，减少主线程卡顿。

## 2. 新增「订阅中心」块（`petri:sub`）+ 本机订阅代理（`sub/`）
- 在本机通过 `sub/server.mjs`（默认 `127.0.0.1:4135`）把你已有的订阅账号转成标准 OpenAI 兼容接口，登录完成后一键同步进「AI 配置」供全系统调用。
- 已内置 **5 家订阅驱动**：
  - **Cursor**（官方 `@cursor/sdk`，浏览器一键登录或贴 `crsr_...` Key）
  - **Grok Build**（xAI 设备码 OAuth，支持对话、思考、工具、生图、生视频）
  - **Antigravity**（Google OAuth，支持 Gemini / Claude 思考模型）
  - **ChatGPT**（支持 SIWC 与 Codex OAuth 双通道）
  - **Claude**（Claude Code OAuth + `/messages` 透传）
- 真实凭证仅存本机 `tokens/` 目录，不进 `colony.html`、不上传云端。

## 3. 插件管理（`petri:plugin-manager`）：全新通用「网页插件」引擎
- 新增通用动态运行时段（`网页模型` + `协议适配`），不把任何站点逻辑写死在插件管理源码里。
- 支持用 `plugin.web.explore` 输入任意网址自动探索网站能力并封装成网页插件，可挂载进 AI 配置当作普通大模型调用，也可作为独立工具插件调用。
- 随包附带 4 个已实测跑通的网页插件（`web-plugins/`）：
  - **Grok (网页)**：Grok 4.7 五模式对话 + Imagine 批量超清生图/改图 + 并发批量生视频 + 照片库/配额
  - **Gemini (网页)**：Gemini 4 对话 + 制作图片（改图/GIF）+ Veo 视频 + Lyria 音乐 + 库/用量
  - **Muse (网页)**：1600×1600 文生图 + 720p 文生视频
  - **PriceAI 比价雷达**：免登录纯 HTTP 查询官方低价区、卡网报价、API 套餐与中转站倍率

## 4. 浏览器插件 `Colony Bridge`（`plugin/`）升级
- **`bg.js`**：新增零黄条折叠静默后台标签（`bgTab`）、MAIN 世界页内执行（`runPage`）、iframe 帧注册（`frameReg`）、站点 Origin 请求伪装（`withSiteOrigin`）以及 Cloudflare 风控 Cookie 保护。
- **`manifest.json` / `rules.json` / `cs.js`**：将 `iframe-hook.js` 排除 Cloudflare 校验页，移除全局静态 `sub_frame` 剥离规则改为按需动态生效，大幅降低对正常网站风控的干扰。
- **`colony-gateway.mjs`**：升级为流式 `spawn` 引擎，支持附件落盘与 `--add-config`。

## 5. 其他块与本机脚本优化
- **AI 配置（`petri:ai`）**：增强协议适配、模型调用与多模态通道，支持网页模型协议无缝接入。
- **工作流（`petri:workflow`）**：AI 节点补全音频、视频与通用文件附件输入输出。
- **本机（`petri:local` + `local/colony-local.cjs`）**：编辑同一文件自动排队防覆盖、返回改动 diff、读文件字数智能封顶、默认命令等待调整为 20 秒。
- **agent 桥接（`petri:bridge`） / 次元口袋（`petri:porter`）**：精简自报与界面数据体验优化。
- **浏览器小应用（`miniapps/browser.html`）**：支持 🤖 静默协作标签页与一键清理。
