# Colony 11.26 更新说明

对比上一版 `release-2026-11-07`（v11.7）。本版完成 **单进程双端口聚合网关（私有 OpenRouter / 替代 CLIProxyAPI）+ AI 配置一体化合并订阅与纯插件手机端 + 全能 agent 重构 + 通用网页插件引擎 + Colony Bridge v0.6**。

## 1. 本机层重构：单进程双端口物理隔离 + 私有 OpenRouter 网关
- **从双进程缩成 1 个进程**：`local/colony-local.cjs` 启动后在同进程内自动挂载 `sub/gateway.mjs`（没装订阅目录时也能零依赖起兜底 `/proxy`）：
  - **控制面 `:4130`**：代码强制锁死 `127.0.0.1`（禁止外放），负责跑命令、读写文件与源码快照。
  - **数据面 `:4135`**：独立路由表物理隔离（无任何 shell/文件能力），完整覆盖 CLIProxyAPI：
    - 同时支持 **OpenAI `/v1/*`**（对话/Responses/生图/音视频）与 **Anthropic `/v1/messages`**（Claude Code / Cline / Codex CLI / Cherry Studio 开箱即连）。
    - **三源全聚合**：5 家订阅（Cursor / Grok Build / Antigravity / ChatGPT / Claude）+ `AI 配置` 勾选同步的常规 API 厂商（不暴露上游 Key）+ **浏览器网页模型反向桥接**（浏览器开着 Colony 时外部工具也能经 `4135/v1` 调用 Grok / Gemini / Muse 网页模型）。
    - **安全且省心**：默认仅听 `127.0.0.1` **本机免密**（留空或填 `123456` 等任意占位 Key 均通）；主动开启局域网外放（`0.0.0.0`，默认关闭）时热切监听并校验**可自定义编辑的外放密码**（自动过滤虚拟网卡只报真实局域网 IP）。
    - 内置 `/proxy?url=...` 透明流式代理，给无插件环境下的中转站解决 CORS 跨域。

## 2. `AI 配置`（`petri:ai`）升级为统一模型中枢（9 块更精简，退休独立订阅块）
- **合并订阅与网关面板**：顶部新增 `🧠 厂商配置` | `🔑 订阅与网关` 双页签，一站管常规 API Key、5 家本机订阅、聚合厂商勾选、局域网外放与接入地址；**单块独立导出 `petri-ai.html`（~133 KB）**即可独立当私有 OpenRouter 控制台。
- **密码管理统一**：所有密码输入框（API Key、自定义外放密码、粘贴订阅 Key）右侧统一增加 **`👁` 显隐切换** 与 **`📋` 一键复制**，保留浏览器自动填充便利性。
- **CORS 三层无感自动回退**：显式填了「转发地址」按转发地址走（留给纯手机无插件无本机用户）；未填时直连遇跨域自动阶梯回退 **插件转发 → 本机 `4135/proxy`** 并记住通路。
- **纯插件订阅模式（兼顾手机浏览器装扩展）**：未连接本机进程时自动切入 **🧩 纯插件订阅模式**，零本机进程直连 **Grok Build / ChatGPT / Claude / Antigravity** 4 家 OAuth（Cursor 提示需本机）。

## 3. 浏览器插件 `Colony Bridge` 升级至 `v0.6`（`plugin/`）
- **本地 `file://` 单文件本体满血解锁**：经顶层 Colony 页面签名校验后，双击本地 `colony.html` 或 `petri-ai.html` 同样享有跨站免 CORS（含流式）、纯插件 OAuth 与网页模型能力。
- **2 个通用零硬编码原语**：临时 `declarativeNetRequest` 请求头改写（发完即清，SW 重启自动扫清残留规则）+ 三重 `oauthIntercept` 回调拦截（`onBeforeNavigate` / `onErrorOccurred` / `tabs.onUpdated`）+ 扩展独立 `subStore` 存储。
- **零黄条静默后台页与风控保护**：`bgTab`、`runPage`、`frameReg`、`withSiteOrigin`、Cloudflare 校验页排除；内置扫描新增 `:4135` 聚合网关；`colony-gateway.mjs` 升级流式 `spawn` 引擎。

## 4. 全能 agent、网页插件引擎与其他块升级
- **全能 agent（`petri:agent`）**：完成第 1 档 5 项架构重构（主/worker 共用引擎、动态截断与阶梯折叠、精简系统提示与按需自报、对话栏懒加载）。
- **插件管理（`petri:plugin-manager`）**：全新通用动态「网页插件」引擎，附带 4 个干净即用网页插件（`web-plugins/`：Grok、Gemini、Muse、PriceAI 比价雷达）。
- **本机（`petri:local`）**：面板新增「同进程聚合网关（:4135 数据面）」实时状态卡片与快捷跳转，编辑排队/diff/20s 默认等待。
- **工作流（`petri:workflow`）**：AI 节点补全音视频与通用文件附件；新版「浏览器」小应用支持 🤖 静默协作标签。
